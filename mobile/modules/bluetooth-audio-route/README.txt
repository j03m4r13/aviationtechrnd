Bluetooth Audio Route replacement files

1. In the Aviation project root, run:
   npx create-expo-module@latest --local

2. Use this module name when prompted:
   bluetooth-audio-route

3. Copy the contents of this folder over:
   modules/bluetooth-audio-route/

   Keep the package.json, android/build.gradle, and podspec generated by the command.
   Replace the matching Android, iOS, src, index.ts, and expo-module.config.json files.

4. Copy AviationVoiceApp.bluetooth-native-route.tsx over your AviationVoiceApp.tsx.
5. Copy audio.bluetooth-native-route.ts over config/audio.ts.
6. Rebuild with:
   npx expo prebuild --clean
   npx expo run:android
